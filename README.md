## How to Use This Repository

### Prerequisites

- Python 3.9+
- Git (for commits)
- Text editor (VS Code, PyCharm, etc.)

### Setup

```bash
# Clone the repo
git clone https://github.com/tejas6433/ai-master-journey.git
cd ai-master-journey

# Create virtual environment (optional but recommended)
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# or
venv\Scripts\activate     # Windows

# Install dependencies (once we get there)
pip install pandas numpy matplotlib seaborn scikit-learn pytorch
```

### Running Code

```bash
# Run a specific Python file
python3 python/oop/01_classes.py

# Run a challenge
python3 python/oop/challenge1.py

# Run a DSA problem
python3 dsa/arrays/contains_duplicate.py
```

### Daily Workflow

1. **Watch** the concept video (Corey Schafer, 3Blue1Brown, StatQuest, etc.)
2. **Code Along** in the appropriate file (`01_classes.py`, etc.)
3. **Challenge** yourself with the problem (`challenge1.py`)
4. **DSA** (1-2 problems per day, concept-first approach)
5. **Commit** your work with a meaningful message

```bash
git add .
git commit -m "Learn: [topic] - [resource]"
git push
```

## Learning Strategy

### Concept-First (Not Problem-Grinding)

```
Learn Concept → Code It → Do 1-2 Problems → Move On
```

Don't jump to Neetcode problems blindly. Learn the **why** first.

Example (DSA):
1. Watch NeetCode video on **Two-Pointer Technique**
2. Code a two-pointer implementation yourself
3. Solve 1-2 two-pointer problems
4. Move to the next technique

### Daily Pace

- **Core Learning:** ~2 hrs/day (videos + coding along)
- **DSA:** ~1 hr/day (1 concept or 1-2 problems)
- **Total:** ~3 hrs/day sustained
